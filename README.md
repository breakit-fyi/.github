# 💥 breakit.fyi
**Break it till you make it.**

Hands-on DevOps & SRE experiments: break real systems, then learn how to fix them.

`💣 break` → `🔍 observe` → `🛠️ fix` → `🧠 understand`

</div>

---

<details>
<summary><b>🧪 What's inside?</b></summary>
<br>

Small, local experiments that recreate **real production failures**: OOMKills, retry storms, DNS issues, cardinality explosions and more.
They run on Docker or `kind` with no cloud bill, and every one is tested in CI.

</details>

<details>
<summary><b>⚡ Try one in 4 commands</b></summary>
<br>

```bash
git clone https://github.com/breakit-fyi/<experiment>.git && cd <experiment>
make break     # 💥
make fix       # 🛠️
make clean     # 🧹
```

</details>
